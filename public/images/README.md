# Fotos

Enquanto os arquivos abaixo não existirem, o site mostra um gradiente no lugar.

| Arquivo | Uso | Tamanho sugerido |
|---|---|---|
| `hero.jpg` | Topo da home: piscina com a praia ou o céu do fim de tarde ao fundo. Enquanto não existir, o site mostra o gradiente com o sol | 1920×1080, até 300 KB |
| `fachada.jpg` | Fachada (página de localização e contato) | 1600×900 |
| `og.jpg` | Prévia ao compartilhar o link no WhatsApp e redes | 1200×630 |
| `rooms/varanda-1.jpg`, `varanda-2.jpg` | Apartamento com Varanda | 1600×1200 |
| `rooms/normal-1.jpg`, `normal-2.jpg`, `normal-3.jpg` | Apartamento Padrão | 1600×1200 |
| `piscina.jpg`, `varanda-vista.jpg`, `cafe.jpg`, `recepcao.jpg`, `centro.jpg` | Galeria da home | 1600×1200 |

Os nomes e textos alternativos estão em `src/data/rooms.ts`.

## Pacotes

Uma foto por pacote em `pacotes/<slug>.jpg` (1600×1000): `fim-de-semana-a-dois`, `retiro-de-descanso`, `semana-em-familia`, `temporada-das-baleias`, `festival-gastronomico`, `reveillon`, `carnaval`, `prado-moto-rock`, `feriado-prolongado`.
