# Fotos originais

Suba aqui as fotos do Drive (qualquer formato: avif, jpg, png, webp). Elas não aparecem no site
diretamente: a partir delas são geradas as versões otimizadas em `public/images/`, `rooms/` e `pacotes/`.

Pelo GitHub: abra esta pasta no navegador → **Add file → Upload files** → arraste todas → **Commit changes**.
